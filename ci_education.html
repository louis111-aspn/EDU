Module 1
연결결산 기초 이론
단일 경제적 실체 관점에서 투자자본상계가 왜 필요한지 이해합니다
1.1단일 경제적 실체(Single Economic Entity)
핵심 개념

연결재무제표는 지배기업과 종속기업을 하나의 경제적 단위로 보고 작성합니다. 법적으로는 별개 법인이지만, 재무보고 목적상 "외부 투자자에게 그룹 전체의 실질적 재무상태"를 보여주는 것이 목적입니다.

📋 지배력(Control) 판단 기준 K-IFRS 제1110호
1
힘(Power)
피투자자의 관련 활동을 지휘할 능력
▾

의결권 과반수(>50%), 계약상 약정, 사실상 지배 등. 단순 지분율이 아닌 실질적 의사결정 능력을 판단합니다.

2
변동이익에 대한 노출
피투자자 성과에 따른 손익 변동
▾

배당, 잔여재산 분배, 서비스 보수 등 피투자자의 성과에 따라 변동하는 이익에 노출되어 있어야 합니다.

3
힘과 이익의 연결
힘을 이용해 이익에 영향을 미치는 능력
▾

단순히 힘이 있고 이익에 노출되는 것만으로는 부족합니다. 힘을 사용하여 이익의 크기에 영향을 미칠 수 있어야 합니다.

Module 2
투자차액 및 비지배지분(NCI)의 이해
취득원가를 분해하여 영업권·공정가치차액·NCI를 산출하는 핵심 계산 구조
2.1공정가치차액(Fair Value Difference)
정의

취득일 시점 종속기업 개별 자산·부채의 장부금액(BV)과 공정가치(FV)의 차이. 연결재무제표에서는 FV 기준으로 자산·부채를 인식하므로, 이 차액을 별도로 인식하고 해당 자산의 내용연수에 따라 상각합니다.

2.2영업권(Goodwill) 및 부의 영업권
이전대가1,000
차감: 순자산FV × 지분율 (900×80%)△ 720
영업권= 280
✅ 영업권 발생 (정상 케이스)

이전대가 > 순자산FV × 지분율


초과 지급의 경제적 의미: 브랜드, 고객관계, 기술력 등 식별 불가 무형자산에 대한 대가. K-IFRS 하에서 상각 없이 매년 손상검사(Impairment Test) 실시.

⚠️ 부의 영업권 (염가매수차익)

이전대가 < 순자산FV × 지분율


취득한 자산이 지급한 대가보다 많은 경우. 계산 오류 가능성 먼저 재검토 후, 이상 없으면 전액 즉시 당기손익(이익) 인식.

2.3기타자본잉여금(Other Capital Surplus)
💡
발생 시점: 지배력 획득 이후, 지배력 상실 없이 지분율이 변동하는 경우 (추가 취득 / 일부 처분 / 종속기업 유상증자 등). 이 경우 영업권이 새로 발생하지 않고, 차액은 자본거래로 보아 기타자본잉여금(자본조정)으로 처리합니다.

2.4비지배지분(Non-Controlling Interests, NCI)
정의

종속기업 순자산 중 지배기업 귀속분이 아닌 부분. 연결재무제표 상 자본의 구성요소로 표시됩니다.

순자산비례 측정 ✅ 순자산FV × NCI 지분율

환율 차이

▾

▾

자회사 배당 결의일 ≠ 모회사 배당수익 인식일 불일치 시 IC Elimination 후 잔액 발생. 결의 즉시 모회사 통보 프로세스 의무화 필요.

▾

5.4해결방안 체계 — Prevention / Detection / Resolution
🛡️ Prevention (사전)
  • IC Ownership 마스터 Lock-down (결산 D-5 이전 변경 금지)
  • 자회사 자본 변동 시 연결팀 즉시 통보 의무화
  • Activity Code 입력을 결산 체크리스트 필수 항목으로 포함
  • FS Item 매핑 Table 주기적 검증
🔍 Detection (탐지)
  • C/I 실행 후 영업권·NCI Roll-forward 자동 검증
  • 대차불일치 발생 시 알림 Rule 설정
  • 전기 대비 영업권 변동 분석 (손상 외 변동 원인 규명)
  • NCI 잔액 × 지분율 역산 검증
🔧 Resolution (해소)
  • 수동 JE: Document Type 분리 (자동 vs 수동 구분)
  • 2-Level 승인 (담당자→팀장) 프로세스
  • 계산 근거 Excel 아카이빙 의무화
  • 동일 수동 JE 2기 이상 반복 시 자동화 전환 검토

C/I 완전 정복 — 핵심 체계
  • M1 기초: 이중계상 방지 → C/I는 투자주식과 자본을 상계하고 영업권·NCI를 새로 인식하는 창조적 조정
  • M2 분해: 이전대가 = 순자산FV × 지분율 + 영업권 / NCI = 순자산FV × NCI 지분율 (순자산비례)
  • M3 이벤트: 6개 이벤트 × [별도분개 → 연결조정분개 → 잔액 검증] 3단 구조
  • M4 시스템: Activity Code 정확도 = GR 자동화 품질. 복잡 이벤트는 수동 JE 불가피
  • M5 실무: P1 리스크(Activity Code 누락·환율 Mismatch) 우선 통제. 수동 JE 4원칙 준수
  • M6 종합: 분개 ①~⑧ 전체 대차 균형 확인. Roll-forward로 NCI·영업권 잔액 검증
