01
업무 구조의 문제
GAP 분석, 요건 정의서 초안, 오류 로그 해석, T-Code 매핑 문서화 — 이 모든 업무는 고반복·저판단 구조다. 컨설턴트의 가치는 여기서 나오지 않는다.
02
기술 임계점 도달
LLM + Tool Use + Memory + Orchestration이 실무 수준에 진입했다. SAP Help Portal, OSS Note 기반 RAG 구성이 이미 현실화되어 있다.
03
경쟁 환경의 변화
SAP Joule가 S/4HANA에 내재화되었고, 클라이언트가 AI 도구를 먼저 보유하는 역전 현상이 시작됐다. 컨설턴트의 차별점은 판단력뿐이다.

Section 03

3단계 도입 로드맵

Assist → Automate → Augment의 단계적 전환으로 리스크 없이 AI 에이전트를 SAP 프로젝트에 내재화할 수 있다

Phase 1
Assist
0 – 3개월
  • OSS Note 요약 봇 사용
  • 회의록 → 액션 자동 구조화
  • 오류 로그 1차 원인 분석
  • Claude / ChatGPT 프롬프트 설계 연습
  • 팀 공유 프롬프트 라이브러리 구축
→
Phase 2
Automate
3 – 6개월
  • GAP 분석 에이전트 워크플로우
  • Config 설정 → 설계문서 자동 업데이트
  • 비즈니스 시나리오 → UT/SIT 케이스 생성
  • GR IC 제거 이상 자동 알림
  • SAC 모델 변경 이력 자동 문서화
→
Phase 3
Augment
6개월~
  • 전략 질문 → 에이전트 데이터 수집·분석
  • ACDOCU 이상 → 자동 원인 가설 제시
  • 컨설턴트는 "질문의 질"과 "최종 판단"에 집중
  • 멀티 에이전트 오케스트레이션 설계
  • AI 감리(Audit) 역할 확립
⚠ 주의: Phase를 건너뛰지 마라

Phase 1 없이 Phase 2로 진입하면 프롬프트 설계 실력 없이 자동화를 구성하게 된다. 에이전트 출력의 오류를 감지하는 능력은 직접 사용 경험(Phase 1)에서 나온다.

Section 05

컨설턴트 역량 재정의

AI 에이전트 시대의 SAP 컨설턴트는 T-Code 숙련도보다 '질문 설계력'과 '에이전트 감리 능력'이 핵심 역량이 된다

역량 영역 기존 핵심 역량 AI 에이전트 시대 핵심 역량
기술 숙련도 T-Code 암기, Config 설정 경험, 트랜잭션 순서 숙지 프롬프트 설계, Tool Use 통합 이해, 에이전트 오케스트레이션
분석·진단 데이터 직접 추출·가공, 수동 오류 원인 추적 에이전트 출력값 검증·비판, 가설 기반 질문 설계
문서화 템플릿 직접 작성, 회의록 수기 정리 에이전트 초안 → 비즈니스 맥락 기반 판단·편집
커뮤니케이션 정보 수집·전달, 회의 요약 맥락 설계, 의사결정 촉진, AI 결과 해석 통역자
차별화 요소 도구 숙련도, 경험 기반 직관 비즈니스 판단력 + AI 감리 능력 + 질문의 질
GR / SAC 특화 수동 IC 조정, 연결 분개 처리, SAC 수식 직접 작성 에이전트 탐지 결과 검증, 자동화 예외 처리 설계
01
Prompt Engineering
모호한 업무 요청을 AI가 처리 가능한 구조화된 지시로 변환하는 능력. 좋은 프롬프트는 좋은 요건 정의서와 같다. SAP FI/CO 컨텍스트를 프롬프트에 녹이는 훈련이 핵심.
02
Output Verification
에이전트 결과물의 오류·편향·누락을 감지하는 비판적 사고. AI는 자신 있게 틀린다. GR 분개 초안의 차변/대변 논리, IFRS 기준 적합성을 검증하는 도메인 지식이 방어막이다.
03
Agent Orchestration
여러 에이전트를 조건·순서에 따라 연결하는 설계 능력. "IC 오류 탐지 에이전트 → 원인 분류 에이전트 → 분개 초안 에이전트"처럼 워크플로우를 설계하는 시스템 사고.
Section 06

즉시 실행 가능한 Quick Win

별도 인프라 없이 지금 당장 시작 가능한 7개 시나리오로 팀 내 AI 에이전트 적용을 가시화할 수 있다

1
OSS Note RAG 봇 — SAP 오류코드 즉시 해석
오류코드(예: Message no. F5 702)를 입력하면 관련 OSS Note를 검색·요약하고 조치 방안 후보를 제시. 신규 컨설턴트의 가장 큰 시간 낭비 영역. Claude/ChatGPT에 SAP Note PDF를 업로드하거나 RAG 구성.
Claude / ChatGPT 1~2h → 10분/건 난이도 ★☆☆
2
회의록 → 액션 아이템 자동 구조화
회의 녹취 텍스트 또는 수기 메모를 붙여넣으면 담당자·기한·이슈 분류가 자동 생성. 프롬프트에 "SAP 프로젝트 컨텍스트"와 "JIRA 티켓 형식"을 지정하면 바로 활용 가능.
Claude + 템플릿 프롬프트 30분 → 5분/회의 난이도 ★☆☆
3
FIT-GAP 분석 초안 에이전트
인터뷰 내용(AS-IS 프로세스 설명)을 입력하면 To-Be 요건 후보와 GAP 매트릭스 초안을 생성. "SAP S/4HANA 표준 기능 범위"를 시스템 프롬프트에 주입하면 정확도가 크게 향상됨.
Claude + 구조화 프롬프트 반나절 → 1시간 난이도 ★★☆
4
K-IFRS / IFRS 체크리스트 검토봇
결산 데이터 요약 또는 재무제표 수치를 입력하면 IAS 28(지분법), IFRS 16(리스), IFRS 18(재무보고) 체크리스트를 기준으로 위험 항목을 자동 플래그. 컨설턴트는 플래그 항목만 심층 검토.
Claude + 체크리스트 임베딩 수작업 검토 50% 절감 난이도 ★★☆
5
GR IC 불일치 자동 탐지 스크립트
ACDOCU 또는 GR 리포트 CSV를 입력하면 법인 간 IC 거래 불일치를 자동 탐지하고 차이 원인 후보를 제시. Python + Claude API 조합으로 팀 내 소규모 자동화 구현 가능.
Python + Claude API 수시간 → 자동 알림 난이도 ★★☆
6
UT/SIT 테스트 시나리오 자동 생성
비즈니스 프로세스 설명(예: "구매발주 → 입고 → 청구서 수령 → 지급")을 입력하면 정상 시나리오·예외 시나리오·엣지 케이스를 포함한 테스트 케이스 목록을 자동 생성.
Claude + 프로세스 문서 2일 → 3시간 난이도 ★★★
7
SAC 수치 이상 탐지 + 경영진 주석 초안 생성
SAC Story의 KPI 데이터를 CSV로 추출 후 입력하면 전월 대비 급변 항목을 탐지하고 경영진 보고용 주석 초안을 생성. 매월 반복되는 보고서 준비 시간을 대폭 절감.
Claude API + SAC CSV 추출 4시간 → 1시간 난이도 ★★★
