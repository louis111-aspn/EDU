Section 03
회계기준 변환 (Reclassification)
ASPN Korea는 K-GAAP 기준으로 결산한다. 그룹 IFRS 기준으로 통일하기 위해 계정 재분류 및 조정분개를 수행한다.

왜 변환이 필요한가

Korea의 K-GAAP FS를 그대로 합산하면 그룹 IFRS 기준과 불일치가 발생한다. 대표적인 차이 항목은 다음과 같다.

개발비 요건 충족 시 자산화 IAS 38: 엄격한 자산화 요건 요건 미충족분 비용 처리

GR — Reclassification Task

GR에서는 법인별로 Reclassification Rule을 설정하여 자동 변환이 가능하다. FS Item 간 매핑 룰로 정의되며, 반복 기간마다 동일하게 적용된다.

설정 방식
FS Item 매핑 룰

K-GAAP 계정(Source FS Item) → IFRS 계정(Target FS Item)으로 자동 재분류. 금액 비율 지정도 가능.

적용 범위
법인 단위 설정

Korea에만 적용되는 룰로 설정. Europe은 IFRS로 이미 작성되어 변환 불필요.

확인 문제

ASPN Europe은 IFRS 기준으로 결산한다. GR에서 Reclassification Task를 Europe에 적용해야 하는가?
네. 모든 법인에 동일하게 적용해야 한다
아니오. IFRS로 이미 작성된 법인은 변환이 불필요하므로 적용하지 않는다
EUR 통화 법인이므로 통화 변환 목적으로 적용해야 한다

기간 간 연속성 — Carry Forward
연결 조정은 매 기간 독립적으로 발생하지 않는다. 전기 조정액은 당기로 이월되고, 전기 미실현이익은 당기에 실현 처리된다.

두 가지 Carry Forward 개념

개념 1
잉여금 이월

전기에 수행한 C/I, IC 제거 등 연결조정으로 발생한 자본 조정액(영업권, NCI 등)이 당기 기초 잔액으로 이월된다. GR은 Carry Forward Task를 통해 이를 자동 처리한다.

개념 2
미실현이익 실현 처리

전기에 소거한 재고 미실현이익은 해당 재고가 외부에 판매되는 당기에 역분개(반대 분개)를 통해 실현된다. 전기 소거 → 당기 실현의 2단계 구조.

시나리오 — 재고 미실현이익의 기간 간 처리

기간상황연결조정그룹 손익 효과
20X1년 (전기) Korea가 Holdings에 재고 판매. Holdings가 미판매 보유 중. 미실현이익 5억 포함. 미실현이익 소거: 매출원가 +5, 재고 △5 그룹 이익 △5억
20X2년 (당기) Holdings가 해당 재고를 외부 고객에게 전부 판매 완료. 역분개(실현): 재고 +5, 매출원가 △5 그룹 이익 +5억 (실현 인식)

분개 충돌 구조 — 이월분개와 실현분개가 만나는 지점

20X2년에는 두 개의 분개가 동시에 존재한다. 전기 소거의 이월분개와 당기 실현분개가 재고 계정에서 정면으로 충돌하면서, 최종적으로 재고 계정이 소멸하고 잉여금과 매출원가 분개만 남는다.

핵심 해석
최종 잔류 분개의 의미: 이익잉여금(차변) → 매출원가(대변)

전기에 잉여금에서 차감해두었던 미실현이익 5억이, 당기에 해당 재고가 외부 판매되면서 매출원가를 5억 감소시키는 형태로 이익에 실현된다. 즉, "전기에 못 인식했던 이익을 당기 매출원가 감소로 되찾는 구조"다.
GR Carry Forward
GR은 전기 연결조정 내역을 기억하고 당기 기초에 자동으로 이월한다. 미실현이익 소거의 역분개도 GR이 자동 처리하므로, 담당자가 전기 조정 내역을 수동으로 추적할 필요가 없다. 단, 재고 판매 여부(실현 여부)는 법인이 정확히 신고해야 한다.
누적 오류의 위험
전기 Carry Forward가 잘못되면 당기 연결 결과 전체가 왜곡된다. 특히 영업권 상각, NCI 누적 조정, 미실현이익 잔액은 기간이 누적될수록 오류가 복리로 증폭된다. 결산 시작 전 전기 이월 잔액 검증이 필수다.
