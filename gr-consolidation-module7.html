연결 현금흐름표 특유 항목

항목분류연결 특이사항
이자 수취 영업 또는 투자활동 (선택) 내부 이자(Holdings↔Korea 3억)는 제거. 외부 이자만 표시.
이자 지급 영업 또는 재무활동 (선택) 동일 원칙 적용. 선택한 분류를 일관되게 유지.
배당 수취 영업 또는 투자활동 (선택) 자회사 배당(Korea→Holdings 6.4억)은 연결에서 제거. 관계기업 배당(Tech→Holdings 1.2억)은 투자활동으로 표시.
배당 지급 재무활동 지배주주에 대한 배당만 표시. NCI에 대한 배당도 재무활동.
종속기업 취득 투자활동 취득 시 인수한 현금 차감 후 순액 표시.
핵심 원칙 — 내부거래 제거
연결 현금흐름표에서도 그룹 내부 현금 이동은 제거한다. Holdings → Korea 대여금 100억은 그룹 외부 현금 유출이 아니므로 투자활동에 표시하지 않는다. 외부 차입·상환만 재무활동으로 표시한다.
GR — Cash Flow 리포팅
GR에서 현금흐름표는 FS Item에 현금흐름 분류(영업·투자·재무)를 태깅하여 생성한다. 간접법 기준으로 당기순이익에서 출발하여 비현금 조정 항목을 FS Item 계층으로 구성하는 방식이 일반적이다.

ASPN GR 애드인 — 연결주석 자동화 파이프라인

연결주석 작성은 법인별 개별주석 수집부터 환산·합산·조정을 거쳐 연결주석 리포팅까지 이어지는 다단계 프로세스다. ASPN GR 애드인은 이 전 과정을 GR 원장 데이터와 연동하여 자동화한다.

1
주석 양식 관리 연결주석 양식 템플릿을 중앙에서 관리. 항목별 수집 기준과 작성 가이드를 법인별로 배포.
애드인 기능
양식 버전 관리 / 항목별 작성 규칙 설정
2
개별법인 주석 작성 각 법인(Korea·Europe 등)이 애드인 내에서 직접 개별주석 작성. 수치 입력 및 서술형 텍스트 모두 지원.
애드인 기능
법인별 입력 화면 / 항목별 유효성 검증
3
환산 · 합산 · 조정 외화 법인(Europe) 주석 수치를 표시통화(KRW)로 환산. 법인별 주석을 합산하고 연결조정(IC 제거 등) 반영.
애드인 기능

핵심 기능

애드인 기능
최종 리포트 출력 / Audit Trail 생성
GR 원장 정합성 비교의 의미
주석 수치와 재무제표 본문 수치가 다르면 감사 지적 사항이 된다. 기존에는 담당자가 수동으로 대사했으나, ASPN GR 애드인은 GR 원장을 직접 참조하여 주석 작성 단계에서 실시간으로 불일치를 감지한다. 결산 막바지 오류 수정 부담을 크게 줄이는 핵심 기능이다.
